Cloud sharing for Mac

Create a cloud link from your file manager

Select a local item in MiMiNavigator and choose Share+Link from its context menu. Use Google Drive or Dropbox for view links, or send a media file to your own Cloudflare R2 bucket for a direct public URL.

Choose a provider

Google Drive, Dropbox, or Cloudflare R2

01

Google Drive

MiMiNavigator uploads the selected item to a personal Google Drive public folder, applies view permission, and copies the resulting share link. Google Desktop OAuth credentials and Drive API access must be configured first.

02

Dropbox

MiMiNavigator copies the selected item into the Dropbox Public folder and creates a shared view link. A Dropbox API app with the required sharing permissions and a refresh token must be configured.

03

Cloudflare R2 media

Upload an image, video, or audio file to your own public R2 bucket and copy its direct URL after the transfer succeeds. R2 starts disabled; enable it and provide the bucket, public URL, and bucket-scoped S3 keys in Settings.

Copied to the clipboard

Short link when configured

If you configure an optional TinyURL API token, MiMiNavigator creates a mimiNavi short link for Google Drive or Dropbox. Otherwise it copies the provider link. Cloudflare R2 always copies the direct public URL without shortening.

Setup and access

Your provider account and credentials are required

Each provider has its own enable switch in Settings → Cloud Share+Link. Google Drive and Dropbox use your configured accounts; R2 requires a public bucket and bucket-scoped S3 credentials. A public R2 link remains accessible while the bucket and object are public. To revoke it, delete the object or disable public access.

Does it work in one click?

Once a provider is configured and enabled, start Share+Link from the context menu. MiMiNavigator handles upload or copy and clipboard copying. First-time provider setup and authentication are required.

Is a short link guaranteed?

No. TinyURL shortening is optional. If it is not configured or cannot create a short link, MiMiNavigator copies the original provider link.

Can I set edit permissions?

The documented Google Drive workflow applies view permission, and Dropbox creates a shared link. Check the provider link settings if you need different access behavior.

What other tools are included?

MiMiNavigator also includes a Mac media converter and review-first local Cleanup scans with optional on-device AI review.
