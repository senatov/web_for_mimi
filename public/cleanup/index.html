MiMiNavigator help

How Cleanup works

Cleanup quietly collects candidates for your review. It does not remove files on its own, and its optional AI review is limited to possible leftovers from uninstalled applications.

Feature availability: Automatic scanning is in v0.9.1.5. The sortable table and in-app folder links described below are in the development source after v0.9.1.5; they are not in the published v0.9.1.5 DMG.

Automatic scan

Where it scans and when it pauses

01

Starts on its own

A background task starts with MiMiNavigator. It scans eligible roots in sequence, waits six hours after a full pass, then revisits them. There is no switch to manage.

02

Uses spare capacity

The scan waits while MiMiNavigator is in the foreground, system load is high, or thermal conditions are unsuitable. It resumes when those conditions improve.

03

Remembers progress

SQLite stores completed directory checkpoints and candidate snapshots. After a restart, traversal resumes at the last committed directory. Interrupted hashing can repeat, using cached hashes when valid.

04

Stays within a safe scope

Cleanup visits the home directory and writable local volumes it can access. It does not scan all of macOS: system, cloud, Time Machine, and development locations are excluded.

Review results

Candidates appear gradually

Results accumulate in the Cleanup tab during a scan and remain available across sessions. The standard checks suggest exact file and leaf-folder duplicates, old installers, temporary files, old empty folders, and stale PID files. A suggestion is a reason to inspect an item, not a verdict that it is disposable.

Built-in AI assistance

What the on-device model does

When Apple's on-device Apple Intelligence Foundation Models system model is available and ready, MiMiNavigator can ask it to review possible leftovers from uninstalled applications. The model receives a candidate path and category, not file contents. It returns a conservative KEEP or REVIEW suggestion.

If the model is unavailable, this optional leftover review is skipped. The standard file checks continue to work. An AI suggestion never triggers deletion and does not prove that removing an item is safe.

You decide

Nothing is deleted automatically

Choose individual items or copies in a duplicate group, review the confirmation, and move the selection to Trash only when you are satisfied. Cleanup keeps at least one verified copy in each duplicate group and rechecks candidates immediately before the move.
