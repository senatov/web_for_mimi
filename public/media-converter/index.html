Media tools for Mac

Convert media without leaving your file manager

MiMiNavigator brings media inspection and conversion into a native macOS file workflow. Select a file, review its details and preview, choose an available output preset, then save the converted result alongside your files.

One workflow, common media types

Video, audio, images, and GIFs

01

Video conversion

Choose among presets supported for the selected source, including common MP4/H.264 workflows. Available targets depend on the source and installed conversion tools.

02

Audio conversion

Convert supported audio files using source-aware presets. MiMiNavigator checks for the optional media tools it needs and reports when setup is required.

03

Image conversion

Convert supported image formats through the media workflow. Choose an offered target for the selected file rather than relying on a fixed list of every possible format pair.

04

GIF workflows

Create or convert GIF media using available presets. Some workflows use optional tools such as FFmpeg or gifski; the built-in External Tool Doctor helps check dependencies.

Inside the file manager

Inspect, preview, choose, convert

Open media details for a selected file to inspect metadata and preview it. MiMiNavigator offers source-aware presets, runs conversion through its media tools, and reports the result in the same workspace. It is designed for practical file tasks alongside browsing, copying, and organizing files in two panels.

Conversion depends on the media type and the available encoder tools. FFmpeg is optional and can be installed or diagnosed through MiMiNavigator's external tools settings. Review the available presets in the app for the exact input and output combination.

Questions

Mac media conversion FAQ

Does MiMiNavigator convert only video?

No. Its media workflow includes video, audio, image, and GIF conversion, with available presets determined by the selected file.

Do I need a separate converter app?

MiMiNavigator provides the conversion workflow within its file manager. Some conversions rely on optional external media tools, which the app can help diagnose.
