Questions about the prototype

vpn_key

How do I get provider API keys?

For Finnhub live trades, create a free Finnhub account, copy its key from the dashboard, then save it in Settings → Market data providers → Finnhub. Enter a supported symbol in Radar and select Start feed.

For optional additional candidates, company profiles and daily history, create a free Financial Modeling Prep account, verify your email and copy the key from its dashboard. Save it under FMP in the same Settings page.

Provider limits, market hours and account access apply; keys do not guarantee live prices or signals. Other sources can work without keys. The optional Finnhub webhook secret can be left empty.
