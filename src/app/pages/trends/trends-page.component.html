Features

A scanner built around recency and evidence

MiMiTrends narrows a broad watchlist into a readable set of unusual events without presenting signals as recommendations.

01

Fresh anomaly detection

Detect upward and downward impulses, V-shaped reversals, and steady trends from completed minute-aligned OHLCV bars.

02

Adaptive, explainable ranking

Combine price rarity, candle structure, volume confirmation, continuation, freshness, and historical outcomes into a transparent priority.

03

Performance-led discovery

Merge the first public performance and most-traded pages, sort by percentage performance, and evaluate the leading 30 resolvable equities with the regular quality gates.

04

Repeating-cycle warning

Identify statistically repeating two- or three-minute price paths and place a bright-red ↻ marker beside the cleaned company name.

FAQ

Know what the scanner does—and what it does not

Is MiMiTrends a trading bot?

No. It is informational software: it does not place orders, provide investment advice, or guarantee that a detected anomaly will continue.

Which markets are supported?

The scanner supports configurable US, European, or combined watchlists and supplements them with a bounded first-page set of current public market leaders.

What does the red ↻ mean?

The latest minute bars show a statistically repeating two- or three-minute path. It describes observed cyclic structure; it does not predict that the next phase will repeat.

Do I need an API key?

No key is required for the default data path. Finnhub is an optional enhancement for supported US symbols.

Where is my data stored?

Minute history, profiles, statistics, runs, outcomes, preferences, and imported executions are stored locally in SQLite.

Which platforms are ready?

The application is cross-platform by design. The current UI and builds have been tested on macOS; Windows and Linux packages are implemented but not yet platform-verified.

How is it built?

MiMiTrends is a modular Kotlin/JVM application with a JavaFX desktop interface and Gradle-based native packaging.
