Features

Built for the jobs Finder makes expensive

MiMiNavigator combines TC-style menus and hotkeys with persistent tabs and views, Find Files, Multi-Rename, remote access, Archive VFS, media conversion, and cloud sharing.

01

Dual-panel workflow

Work with two locations side by side, keep your tabs and views between sessions, and manage files with the keyboard or mouse without juggling Finder windows.

02

Find and clean

Find large or forgotten files, empty folders, and application leftovers, then review and process the results together. Anything you remove is sent to the macOS Trash—never deleted permanently by MiMiNavigator.

03

Rename and archives

Rename whole batches with a clear preview, and work with more than 50 archive formats as naturally as you work with ordinary folders.

04

Remote, cloud, and media

Use remote servers, network shares, mounted cloud storage, sharing links, previews, metadata, and media conversion without leaving the familiar two-panel workspace.

FAQ and roadmap

Practical answers for a practical file manager

MiMiNavigator is free, open source, signed, notarized, and still moving quickly.

Why build another file manager for macOS?

Finder is good for casual browsing, but serious file work needs two panels, keyboard shortcuts, visible paths, batch operations, and fewer windows.

Can it replace Finder on macOS 26+?

Yes for file-manager work: persistent dual panels and tabs, List/Preview/Tree views, inline rename, Find Files, SFTP/FTP, SMB/AFP network discovery, mounted cloud storage, Archive VFS, and media conversion are all in one app.

What about file and directory comparison or synchronization?

Comparison and synchronization are large, specialized tasks in their own right. MiMiNavigator deliberately hands selected files or directories to established applications that do this work well. Connect your preferred tools in Settings and keep using the workflow you already trust.

Is file removal safe?

Absolutely. MiMiNavigator removes files and directories only by sending them to the macOS Trash—never by permanently deleting them. What you do with those files in the Trash afterwards, if you are paranoid or enemies are watching you, is none of MiMiNavigator's business.

Which remote and cloud connections are supported?

SFTP and FTP servers open inside the panels with saved Keychain-backed connections. The network neighborhood discovers and mounts SMB and AFP shares. Mounted cloud storage works as part of the file workflow, with dedicated Google Drive and Dropbox Share+Link support.

How do I install it?

Download the signed DMG, open it, drag MiMiNavigator to Applications, and launch it. No App Store and no extra installer.

Is it really free?

Yes. No trial, subscription, or hidden fee. The source is available under AGPL-3.0.

Roadmap

Next direction: a persistent preview pane, saved workspaces, a command bar, Git status badges, duplicate search, direct WebDAV/S3/B2 access, CloudKit settings sync, and deeper Finder integration.
