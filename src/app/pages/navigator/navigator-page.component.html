One workspace, complete flow

From finding a file to delivering it

Search ordinary files, PDF and Microsoft Office content, archives, large forgotten items, empty folders, and application leftovers.

Preview, copy, move, batch rename, and manage archives. Hand comparisons to your preferred external tool.

Browse SFTP and FTP servers, discover SMB and AFP shares, use mounted cloud drives, and treat archives like folders.

Upload to Google Drive or Dropbox and copy a view link from the file context menu. Optional TinyURL shortening creates mimiNavi short links.
Recently improved

Cleanup suggestions you review before acting

Cleanup scans eligible local locations during quiet periods, saves directory checkpoints, and leaves every removal decision to you. The latest media update adds a bundled renderer for Telegram animated stickers.

manage_search

Useful candidates

Review exact duplicates, old installers, temporary files, empty folders, and stale PID files found in your home directory and writable local volumes. System, cloud, development, and Time Machine locations are excluded.

pause_circle

Automatic, resumable scans

Scanning starts with the app; no switch is needed. It waits while MiMiNavigator is active or the Mac is busy, resumes from saved directory checkpoints after a restart, and revisits eligible locations later.

delete_outline

You choose what moves to Trash

Nothing is removed automatically. Select items or duplicate groups, keep at least one copy, and let the app recheck candidates before moving them to Trash.

For scan timing, coverage, on-device AI review, and result handling, read the Cleanup guide.

Features

Tools for everyday file management

MiMiNavigator combines TC-style menus and hotkeys with persistent tabs and views, Find Files, Multi-Rename, remote access, Archive VFS, media conversion, and cloud sharing.

01

Dual-panel workflow

Work with two locations side by side, keep tabs and views between sessions, mirror the active workspace into the opposite panel, and drop files onto the fixed Parent row without juggling Finder windows.

02

Find and clean

Search names and text inside ordinary, PDF, and Microsoft Office files. The Cleanup tab suggests eligible local duplicates and stale items for review; it never deletes them automatically.

03

Rename and archives

Rename whole batches with a clear preview, and work with more than 50 archive formats as naturally as you work with ordinary folders.

04

Remote, cloud, and media

Use remote servers, network shares, mounted cloud storage, sharing links, previews, metadata, and media conversion without leaving the familiar two-panel workspace.

FAQ and roadmap

Requirements, installation, and file handling

Essential information before you install or start working with files.

Why build another file manager for macOS?

MiMiNavigator offers an alternative workflow for people who prefer two panels, visible paths, keyboard shortcuts, and batch operations.

Can it replace Finder on a supported Mac?

Yes for file-manager work: persistent dual panels and tabs, List/Preview/Tree views, inline rename, Find Files, SFTP/FTP, SMB/AFP network discovery, mounted cloud storage, Archive VFS, and media conversion are all in one app.

What about file and directory comparison or synchronization?

Comparison and synchronization are large, specialized tasks in their own right. MiMiNavigator deliberately hands selected files or directories to established applications that do this work well. Connect your preferred tools in Settings and keep using the workflow you already trust.

Can I make the opposite panel match my current workspace?

Yes. Mirror the active path, view mode, thumbnail size, filter, selection, and exact column order, visibility, and widths while leaving the opposite panel's other tabs and history intact.

Is file removal safe?

Local files and supported cloud-provider items use recoverable macOS recycling. SFTP/FTP and other protocol-based servers may not provide a Trash, so remote deletion can be permanent. Review confirmations and keep backups of important data.

Does Cleanup delete files automatically?

No. The automatic scan gradually adds suggestions from eligible local locations to the Cleanup tab. You select what to remove; duplicate groups retain at least one copy, and the app checks candidates again before moving them to Trash. Apple's on-device model can review possible app leftovers when available. See how Cleanup works.

Which remote and cloud connections are supported?

SFTP and FTP servers open inside the panels with saved Keychain-backed connections. The network neighborhood discovers and mounts SMB and AFP shares. Mounted cloud storage works as part of the file workflow, with dedicated Google Drive and Dropbox Share+Link support. See how Share+Link works.

How do I install it?

Download the signed DMG, open it, drag MiMiNavigator to Applications, and launch it. No App Store and no extra installer.

Is it really free?

Yes. No trial, subscription, or hidden fee. The source is available under AGPL-3.0.

Roadmap

Areas under consideration include saved workspaces, direct WebDAV/S3/B2 access, CloudKit settings sync, and deeper Finder integration. Duplicate review, Persistent Preview, the Commander action bar, and read-only Git status are already available today.
